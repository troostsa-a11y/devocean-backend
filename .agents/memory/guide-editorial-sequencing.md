---
name: Guide editorial sequencing
description: Finalize English guide copy before translating language-specific guide pages.
---
Update and approve the English root guide text before undertaking translations.
Fully translated guides remain the intended end state.

**Why:** The owner explicitly wants to avoid translating outdated source text and
then repeating the translation work after editorial corrections.

**How to apply:** Do not treat an indexing report as authorization to translate
unfinished guides or consolidate their locale URLs. Address independently
confirmed routing bugs separately; await an explicit content-update request.
